# NOVA AI LAB

Интерактивный курс по ИИ для шестого класса: 12 миссий, три игры, практический финал «Спаси перемену» и подборка из 10 бесплатных инструментов для дальнейшего обучения.

[Открыть курс](https://ai-school-grade6-beta.neatboot130.chatgpt.site/) · [Раздел «После курса»](https://ai-school-grade6-beta.neatboot130.chatgpt.site/#resources)

## Запуск для проверки

В каталоге `nova-ai-lab` выполните:

```sh
npm test
npm run build:grade6
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Готовая сборка уже лежит в `dist/`, поэтому для просмотра достаточно запустить последнюю команду. Для сборки и тестов нужен Node.js. Прогресс хранится в браузере, на карте доступна кнопка «Начать заново».
