# NOVA AI LAB

Игровой курс по искусственному интеллекту для шестиклассников.

[Открыть курс](https://ai-school-grade6-beta.neatboot130.chatgpt.site/) · [Сыграть в «Спаси перемену»](https://ai-school-grade6-beta.neatboot130.chatgpt.site/#practice)

## Что проверять

12 миссий с разметкой примеров, командами для кота, маршрутами робота, составлением запросов, проверкой фактов и приватностью. В игровом финале ребёнок задаёт условия, испытывает план в трёх ситуациях и сохраняет собственную идею с критерием успеха. Есть три дополнительные игры и раздел бесплатных ресурсов «После курса».

Нова в миссиях работает по учебным правилам. Blockly используется для блоков команд, TensorFlow.js — для сравнения признаков карточек. Прогресс хранится в браузере. Кнопка «Начать заново» находится на карте курса.

## Быстро открыть готовую сборку

Скачайте репозиторий и откройте терминал в каталоге nova-ai-lab. Нужен Python 3.

```sh
python3 -m http.server 8000 --directory dist
```

Перейдите на http://localhost:8000. Каталог dist уже содержит необходимые библиотеки и ресурсы.

## Собрать из исходников

Нужен Node.js 20 или новее.

```sh
npm ci
npm test
npm run build:grade6
python3 -m http.server 8000 --directory dist
```

## Основные файлы

- grade6-next.js — учебный маршрут и навигация.
- practice-game.js — игровой финал и проверка условий.
- quest-scenes.js — визуальные расследования и пошаговая сборка проекта.
- practice.js — сохранение результатов и портфолио, включая совместимость с предыдущей версией.
- cat-blocks.js, lesson-visuals.js — Blockly и классификация карточек.
- test/ — автоматические проверки.
- dist/ — готовая сборка, включая vendor/ и лицензии библиотек.
